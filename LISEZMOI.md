# Site de Diome (Next.js)

Commandes, depuis ce dossier :

- `npm run dev` : aperçu sur http://localhost:3100
- `npm run build` : produit le dossier `out/` (site statique, à héberger tel quel)

Liens des boutons de téléchargement : `lib/config.ts` (vide = bouton grisé « bientôt »).
Consignes par filière : `lib/packs.json` (copie des packs de l'application).
Dans un sous-dossier (GitHub Pages) : `set NEXT_PUBLIC_BASE_PATH=/diome` avant `npm run build`.
